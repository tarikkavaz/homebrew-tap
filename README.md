# homebrew-tap

Homebrew tap for Tarik Kavaz's Mac apps.

## VirtualRemote

Menu bar app that controls the media playing on another Mac on your network.

```sh
brew install --cask tarikkavaz/tap/virtualremote
```

Update with `brew upgrade --cask virtualremote`.

## Cue

Now-playing companion for Spotify Connect with menu bar and desktop widgets.

```sh
brew install --cask tarikkavaz/tap/cue
```

Update with `brew upgrade --cask cue`.

## Posta

Native macOS Gmail client for multiple Google accounts.

```sh
brew install --cask tarikkavaz/tap/posta
```

Update with `brew upgrade --cask posta`.

## Correctify

Menu bar app that corrects grammar and spelling in any app with your own AI provider key. Requires macOS 27.

```sh
brew install --cask tarikkavaz/tap/correctify
```

Update with `brew upgrade --cask correctify`.

## Stabilisator

Menu bar app that levels dialogue and loud scenes across everything your Mac plays, with a volume control for outputs that have none. Beta. Requires macOS 14.2 or later.

```sh
brew install --cask tarikkavaz/tap/stabilisator
```

Update with `brew upgrade --cask stabilisator`.
